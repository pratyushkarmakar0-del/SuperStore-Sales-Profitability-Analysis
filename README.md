# SuperStore-Sales-Profitability-Analysis
Exploratory data analysis of SuperStore sales, profitability, customer segments, and annual growth using Python.
SuperStore Sales & Profitability Analysis
Project Overview

This project performs exploratory data analysis (EDA) on SuperStore sales data using Python. It examines sales performance, profitability, customer segments, regional performance, shipping patterns, and sales growth over time.

Objectives
Analyze overall sales and profitability.
Identify the most profitable and least profitable products.
Compare performance across product categories, regions, and states.
Explore customer sales and profit segments.
Analyze monthly sales trends and year-over-year sales growth.
Investigate shipping duration and potential outliers.
Tools and Technologies
Python
Pandas and NumPy
Matplotlib and Seaborn
Jupyter Notebook

How to Run
Clone or download this repository.
Install the dependencies listed in requirements.txt.
Place the authorized SuperStore CSV dataset in the project folder.
Open SuperStore_Polished_EDA.ipynb in Jupyter Notebook or JupyterLab.
Run the notebook cells from top to bottom.
Dataset

The notebook requires the SuperStore CSV dataset. The dataset is not included in this repository unless it is separately added and licensed for redistribution.
